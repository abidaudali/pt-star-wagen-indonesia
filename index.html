Cara Mengaktifkan Database Realtime (Gratis Google Firebase):

  1. Buka console.firebase.google.com lalu buat Project baru.
  2. Di menu samping, pilih Firestore Database → klik Create database (Pilih mode Test).
  3. Klik ikon gerigi Project Settings → scroll ke bawah, pilih ikon Web </> → salin isi firebaseConfig ke kotak di bawah:
Tekan tombol di atas agar hasil editan di laptop langsung terkirim ke server Cloud.
