# PT. STAR WAGEN INDONESIA - Sistem Manajemen Sparepart & VIB

Aplikasi web modern untuk manajemen inventaris sparepart, tracking stok masuk/keluar, visualisasi dashboard, dan laporan inspeksi untuk PT. STAR WAGEN INDONESIA.

## Fitur Utama

- **Dashboard Real-Time**: Ringkasan total sparepart, status stok (Aman, Menipis, Habis), dan analisis per kategori.
- **Katalog & Manajemen Sparepart**: Pencarian cepat, filter kategori/kondisi/lokasi rak, penambahan, pengubahan, dan penghapusan data sparepart.
- **Transaksi Stok**: Pencatatan barang masuk dan keluar dengan riwayat lengkap dan log aktivitas.
- **Import & Export Excel**: Dukungan integrasi format spreadsheet (.xlsx / .xls) menggunakan SheetJS.
- **Manajemen Hak Akses**: Role Admin dan Viewer dengan kontrol keamanan dan perlindungan aksi krusial.
- **Tema Industrial Dark & Light Mode**: Tampilan responsif yang dioptimalkan untuk desktop dan perangkat mobile/smartphone.
- **Penyimpanan Persisten**: Penyimpanan data otomatis di sisi browser tanpa memerlukan server lokal tambahan (XAMPP/Laragon).

## Teknologi

- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+)
- **Visualisasi**: Chart.js
- **Ikon**: Lucide Icons
- **Pengolahan Excel**: SheetJS (xlsx)
- **Deployment & Hosting**: GitHub & Vercel
